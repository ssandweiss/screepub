# Screepub 0.5.0

This release is about page turns: fewer awkward ones, on more devices.

## Your scripts break better across pages

- **No more orphaned lines.** A printed script never leaves a single line
  of dialogue or action alone at the top or bottom of a page. Screepub now
  does the same. There's a new switch for it, on by default. Turn it off
  if you'd rather fit more on each page.
- **Character names stay with their dialogue on more devices.** This
  already worked on Kindle. It now works in Apple Books and several other
  reading apps, along with side-by-side dialogue when two characters talk
  at once.
- **Apple Books stops changing your formatting.** Your script keeps its
  typewriter font, and lines stay left-aligned the way a script should
  read, instead of being stretched to fill the width.
- **Page numbers stay readable in dark mode.** They used to be a fixed
  gray that disappeared against dark and sepia backgrounds.

## Fixed for older Kindles

Two settings were quietly doing nothing when you saved a file for an older
Kindle. Both work now:

- Start each scene on a new page.
- Include the title page. Switching it off used to remove the title page
  from one file format but leave it in the other.

## Good to know

- The new orphaned-lines setting hasn't been tested on a physical device
  yet. It's based on the device makers' own documentation, and it does
  nothing on readers that ignore it, so it can't hurt.
- Kindles still can't read EPUB files copied over USB. That's Amazon's
  rule, not ours. Screepub converts to a Kindle format for you.

*For the curious: Amazon's published guidelines say modern Kindles ignore
the instructions that hold a page together. Testing on a real Kindle shows
they don't ignore them at all, and Amazon's own website says otherwise
too. Screepub's notes have been corrected to match what devices actually
do.*
