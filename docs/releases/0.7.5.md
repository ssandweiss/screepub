# Screepub 0.7.5

**Report a bug no longer puts your folder or file names in the public page it opens.** This release makes copying, updating and Kindle files harder to break.

## Your books are safer

- **A book survives being unplugged right after a copy.** Unplugging
  the moment a copy finished could leave a cut-off book under the
  book's own name. Now the new copy is fully written before it replaces
  the old one.
- **Kindle files can't hang forever.** Building one with Calibre or
  Kindle Previewer could sit there indefinitely. Now it gives up after
  ten minutes and says so.
- **Updates finish cleanly.** After installing, the window kept working
  against the new version until it restarted, which could fail in odd
  ways. Now it waits for running work, then restarts, offering **Restart
  now** after two minutes. A harmless cleanup hiccup no longer calls a
  good update failed.

## Fixed in the window

- **Convert it again converts again.** It used to take you to the
  Convert page showing the same result, with no way to convert.
- **Long titles and file paths stay inside their boxes.** They used to
  run off the edge.
- **The scene list on Read is one Tab stop.** Tab used to visit every
  scene before the script. Now the up and down arrows move between
  scenes.

## Good to know

- Screepub needs macOS 13 or later, as it always has. On an older Mac it
  used to open and then fail every conversion. Now the Mac says so before
  it opens.
