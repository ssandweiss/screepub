# Screepub 0.5.3

Two things that were quietly telling you something untrue.

## Fixed if you installed with Homebrew

- **Homebrew was six releases behind.** Its listing sat on 0.3.0 while
  everything since shipped past it, so `brew install` and `brew upgrade`
  both left you on old software without ever saying so. It is current
  again. Run `brew update`, then `brew upgrade screepub`, to catch up.

## In the app

- **Cancelling Save a Copy clears its prompt.** Backing out of the save
  window used to leave "choose where to save" sitting under the buttons
  until your next conversion, as though Screepub were still waiting for
  you to pick somewhere.

*For the curious: the Homebrew fix was written and verified back at 0.4.2,
then never committed, so our own notes recorded it as done while the
listing kept serving 0.3.0. A check now reads what is actually published
rather than anyone's local copy, so a listing that falls behind fails
loudly instead of sitting there quietly.*
