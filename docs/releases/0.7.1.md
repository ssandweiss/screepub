# Screepub 0.7.1

**The window can now look for a newer Screepub, and only if you switch it on.** This is 0.7.0, complete: that release went out without the window's downloads, because of a signing mistake on our side.

## The window does more of what the Mac app does

- **Screepub can tell you when a newer version exists.** Open the version
  stamp at the foot of the page and, under Updates, turn on **Look for a
  new version once a day**. Off by default, and nothing is sent but the
  request itself. Installing swaps the app in place, then you quit and
  reopen. macOS only for now.
- **Page numbers are on by default, in both apps.** They were off because
  we called them furniture. They are the script's coordinate system: a
  note that says "the beat on 42 is late" needs page 42 to exist. Turn off
  **The PDF's page numbers** in Settings for a cleaner page.
- **Show in Finder.** The finished book used to be a path printed on
  screen. The result screen now reveals it, selected. On Windows the
  button says Show in File Explorer.
- **A refused file offers to report itself.** When a file is not a
  screenplay Screepub can read, the failure screen now opens a pre-filled
  bug report on GitHub, carrying what went wrong.

## Fixed for the Mac

- **The window's Mac download opens without a warning.** 0.6.0's
  `Screepub-Desktop-macOS-universal.dmg` was signed but not notarized, so
  macOS refused to open it. This one is notarized, and the release checks
  it before publishing.

## Good to know

- This is the first version that can update itself, so 0.6.0's window
  will not hear about it. Download this one by hand, and the next can
  arrive on its own.
- The update switch is absent on Linux and Windows for now.
- `Screepub-macOS.dmg` is still the Mac app we support. The window's
  updater updates only the window.
