# Screepub 0.7.2

**The Linux and Windows downloads keep the same names from now on.**

## Downloads that stay put

- **The Linux and Windows files have names that won't change.** They used
  to carry the version number, like `Screepub-0.7.1-setup.exe`, so a saved
  link broke at the next release. They are now `Screepub-linux-amd64.deb`,
  `Screepub-linux-x86_64.rpm` and `Screepub-windows-x64-setup.exe`, at
  every release.

## Good to know

- If your Mac runs 0.7.1's window with updates switched on, this is the
  first release it can install for itself. It asks before installing, and
  afterwards you quit and reopen.
