# Screepub 0.7.3

**The window can now open Amazon's and Calibre's web pages and fetch one Calibre plugin, each only when you press its button.** It sends a script every way the Mac app does, and finishes its own updates.

## The window catches up with the Mac app

- **Send a script anywhere from the Send page.** It used to copy
  only to a reader plugged in over USB. Now it also adds the book to Apple
  Books, hands it to Amazon's Send to Kindle, attaches it to an email, or
  saves a copy where you choose.
- **The best Kindle file, set up and ready.** On a Mac or Windows PC, the
  Send page checks for the three free tools that build it, and
  installs the KFX plugin for you. When you send to a Kindle, the file now
  builds as the page opens, instead of seeming stuck for half a minute.
- **Your own starting point, and your own folder.** **Use these for new
  scripts**, on the Settings page, makes one script's settings the start
  for every PDF you convert next. **Change…** on the Convert page picks
  where books are saved.

## Fixed in the window

- **Updates restart Screepub for you.** They used to install quietly and
  wait for you to quit and reopen. Now **Update to** appears beside the
  version stamp. Click it, and Screepub installs, waits for any work in
  progress, and reopens. The daily-check switch also stops looking off
  after every restart.
- **You can drag the window.** On a Mac it has no title bar, so there
  was nowhere to grab it. Drag the empty strip along its top.
- **Side-by-side dialogue switches back on.** Once a script showed two
  characters talking at once one after the other, switching back did
  nothing.

## Good to know

- Updating from 0.7.2 still ends with a quit and reopen, because 0.7.2
  can't restart itself.
- Amazon silently drops an emailed book unless it comes from an address on
  your approved list. The email row's **Open Amazon's page** opens the
  page that holds it.
