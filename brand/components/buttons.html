The brad button is the page's one brass object besides the fasteners, so there is never more than one on screen. Disabled is held at 35% opacity, not hidden: it is waiting for hardware, and saying so is the point. The label uses --ink-on-brass, which is fixed in both modes because brass is: 7.98:1 either way. Plain --ink would flip to cream in dark mode and land at 1.67:1. The download is an <a> and the others are <button>, which is why the hover rules key off :not(:disabled) and not :enabled: an anchor never matches :enabled, so the real download link would have silently had no hover at all.
